# Security

SignalDesk is a local demonstration without authentication or tenant isolation. Run it on localhost with synthetic data. Do not expose it to the public internet or treat it as a production service.

For a suspected vulnerability, contact Umer Mughal privately through the [LinkedIn profile](https://www.linkedin.com/in/umermuxhal/) identified in the project README. Do not post credentials, customer records, raw provider responses or exploit details in a public issue. No response-time or support commitment is offered.

If a credential is exposed, revoke or rotate it with the provider. Removing it from source or Git history does not revoke access. Dependency and secret scanning reduce risk but cannot establish the absence of vulnerabilities or secrets.
